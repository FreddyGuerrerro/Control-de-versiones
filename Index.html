Contexto

El proyecto “Eres todo un Cerebrito” fue creado como una plataforma de aprendizaje interactiva enfocada en fortalecer conocimientos mediante actividades dinámicas y contenido educativo.

El sistema busca ofrecer una experiencia amigable para estudiantes y usuarios interesados en practicar habilidades cognitivas, aprendizaje y desarrollo de competencias básicas.

Briefing del Proyecto

Este proyecto fue desarrollado utilizando tecnologías web como HTML, CSS y JavaScript. Además, se implementó control de versiones con Git y GitHub para gestionar cambios, contribuciones y publicación del proyecto mediante GitHub Pages.

La página toma como referencia visual el proyecto “Movimientos Tienda”, manteniendo un diseño moderno, organizado y fácil de navegar.
