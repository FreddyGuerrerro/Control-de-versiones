Contexto del Proyecto

El proyecto “Eres todo un Cerebrito” fue desarrollado como una plataforma educativa interactiva orientada al aprendizaje dinámico mediante actividades y contenido visual.

La plataforma busca mejorar la experiencia de aprendizaje utilizando herramientas digitales accesibles y fáciles de utilizar para estudiantes y usuarios en general.

Briefing

El proyecto utiliza tecnologías web como HTML, CSS y JavaScript, además de herramientas de control de versiones como Git y GitHub para administrar los cambios del sistema.

El diseño está inspirado en el proyecto “Movimientos Tienda”, utilizando una estructura moderna, organizada y responsive.
