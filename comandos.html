Comandos Git

git add

Permite agregar archivos al área de preparación.

git add .
git commit

Guarda los cambios realizados en el proyecto.

git commit -m "Se agregó la página de historias"
git branch

Permite crear y administrar ramas.

git branch desarrollo
git remote

Conecta el proyecto local con GitHub.

git remote add origin https://github.com/FreddyGuerrerro/Plataforma-de-Aprendizaje-Eres-todo-un-Cerebrito.git
git push

Envía los cambios al repositorio remoto.

git push origin main
git status

Muestra el estado actual de los archivos.

git status
git log

Muestra el historial de commits.

git log
git clone

Permite clonar un repositorio.

git clone https://github.com/FreddyGuerrerro/Plataforma-de-Aprendizaje-Eres-todo-un-Cerebrito.git
