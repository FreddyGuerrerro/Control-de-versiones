Historias de Usuario

Briefing Objetivo Historias Comandos Aportes Conclusión

Historia 1

Como estudiante, quiero acceder fácilmente a actividades educativas para mejorar mis conocimientos de forma dinámica.

Ejemplo: El usuario puede ingresar a juegos educativos y practicar lógica matemática.

Historia 2

Como usuario nuevo, quiero una interfaz sencilla para entender rápidamente cómo funciona la plataforma.

Ejemplo: El menú principal permite navegar entre actividades y contenido educativo fácilmente.

Historia 3

Como docente, quiero recomendar actividades educativas interactivas a mis estudiantes.

Ejemplo: El profesor comparte enlaces de actividades alojadas en GitHub Pages.

Historia 4

Como desarrollador, quiero utilizar Git y GitHub para controlar cambios del proyecto.

Ejemplo: Se realizan commits para guardar nuevas mejoras de diseño y funcionalidades.

Historia 5

Como visitante, quiero acceder desde cualquier dispositivo para utilizar la plataforma en línea.

Ejemplo: El sitio puede abrirse desde computador o celular gracias al diseño responsive.
